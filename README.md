# ERD AI — Android APK (ساخته‌شده با گوشی، بدون کامپیوتر)

این پوشه یه پروژه **Capacitor** آماده‌ست که اپ ERD AI (`www/index.html`) رو به یه اپلیکیشن اندروید واقعی تبدیل می‌کنه.
ساخت APK به‌طور کامل روی سرورهای گیت‌هاب (GitHub Actions) انجام می‌شه — نه روی گوشی، نه روی کامپیوتر. تو فقط فایل‌ها رو آپلود می‌کنی.

## چرا این روش، نه AppMint/Appilix؟
- این پروژه **کاملاً مال خودته** — روی گیت‌هاب خودت، نه وابسته به هیچ شرکتی.
- بعداً هر پلاگین/SDK دیگه‌ای (مثل AdMob) بخوای، خودت اضافه می‌کنی.
- کاملاً رایگانه.

---

## مرحله ۱ — ساخت حساب گیت‌هاب
1. اپ **GitHub** رو از Play Store نصب کن، یا از مرورگر گوشی برو به `github.com`.
2. ثبت‌نام رایگان کن (اگه حساب نداری).

## مرحله ۲ — ساخت مخزن (Repository)
1. روی `+` (بالای صفحه) بزن → `New repository`.
2. اسمش رو بذار مثلاً `erd-ai-app`.
3. `Public` رو انتخاب کن.
4. `Create repository`.

## مرحله ۳ — آپلود فایل‌ها
از مرورگر گوشی برو به این آدرس (به‌جای `username` اسم کاربری خودت رو بذار):
```
https://github.dev/username/erd-ai-app
```
این یه ادیتور کامل (شبیه VS Code) توی مرورگرته که روی گوشی هم کار می‌کنه.

تمام فایل‌ها و پوشه‌های این پروژه رو (با همین ساختار پوشه‌بندی) توش بساز یا آپلود کن:
```
erd-ai-app/
├── www/
│   └── index.html          ← فایل اصلی ERD AI
├── patches/
│   └── MainActivity.java
├── .github/
│   └── workflows/
│       └── build.yml
├── package.json
├── capacitor.config.json
└── .gitignore
```
راه ساده‌تر: توی `github.dev` از منوی سه‌نقطه کنار اسم پوشه گزینه **Upload Files** رو بزن و همه‌ی فایل‌ها/پوشه‌ها رو یکجا انتخاب کن.

بعد از اضافه کردن فایل‌ها، از همون صفحه گزینه **Source Control** (آیکون شاخه‌ای شکل کنار سرچ) → `Commit & Push` رو بزن تا فایل‌ها روی گیت‌هاب ذخیره بشن.

## مرحله ۴ — اجازه نوشتن به Actions
1. برو به صفحه اصلی مخزنت روی `github.com` (نه github.dev).
2. `Settings` → از منوی کناری `Actions` → `General`.
3. پایین صفحه، بخش `Workflow permissions` → گزینه `Read and write permissions` رو انتخاب کن.
4. `Save`.

## مرحله ۵ — اجرای build
- چون فایل `build.yml` رو آپلود کردی و پوش کردی، ساخت APK **خودش شروع می‌شه**.
- برو به تب `Actions` بالای صفحه مخزن؛ یه build در حال اجرا می‌بینی (دایره زرد چرخان).
- صبر کن (معمولاً ۳ تا ۸ دقیقه طول می‌کشه).

## مرحله ۶ — دانلود APK
بعد از اینکه دایره زرد به ✅ سبز تبدیل شد، دو راه داری:
- **راه ساده‌تر:** برو تب `Releases` (توی صفحه اصلی مخزن، سمت راست) → آخرین ریلیز → فایل `app-debug.apk` رو دانلود کن.
- یا: توی همون صفحه `Actions`، روی build کامل‌شده بزن، پایین صفحه بخش `Artifacts` رو پیدا کن و از اونجا دانلود کن.

## مرحله ۷ — نصب
- فایل APK دانلودشده رو باز کن.
- اگه گوشی اجازه نصب از منابع ناشناس رو خواست، تاییدش کن.
- نصب کن و باز کن 🎉

---

## نکات مهم درباره این نسخه از ERD AI

- **دسترسی میکروفون** (برای بخش «صدای بلادرنگ») از قبل توی این پروژه هندل شده (فایل `patches/MainActivity.java`) — لازم نیست کاری بکنی.
- **کلید API پالینیشنز** رو باید داخل خود اپ (بخش راهنما) وارد کنی، دقیقاً مثل نسخه وب.
- این اپ برای کار کردن به اینترنت نیاز داره (چون تصویر/ویدیو/چت از سرور پالینیشنز میاد).

## اضافه کردن AdMob در آینده
وقتی خواستی تبلیغ اضافه کنی، فقط کافیه:
1. توی `package.json`، این خط رو به `dependencies` اضافه کنی:
   ```
   "@capacitor-community/admob": "^6.0.0"
   ```
2. توی `capacitor.config.json`، App ID تبلیغاتت رو اضافه کنی.
3. یه تیکه کد کوچیک جاوااسکریپت به `www/index.html` اضافه بشه که تبلیغ رو صدا بزنه.

هروقت خواستی، بگو تا این بخش رو هم برات آماده کنم.
